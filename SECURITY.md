# Security Policy

## Overview

Thank you for helping maintain the security and reliability of my personal research and professional portfolio website.

This repository powers my GitHub Pages website and contains source code, documentation, research highlights, publications, technical content, and related web assets.

Security reports and responsible disclosures are appreciated and help maintain a secure and trustworthy online presence.

---

## Supported Versions

The latest version of the website source code in the `main` branch is actively maintained.

| Version | Supported |
|---------|-----------|
| Main branch | ✅ Yes |
| Latest deployment | ✅ Yes |
| Older commits | ⚠️ Limited |

Security fixes and dependency updates will be applied to the latest maintained version.

---

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities through GitHub Issues.

If you discover a security issue, please report it privately using:

- GitHub Security Advisories ("Report a vulnerability")
- Email: rkagrawal@ieee.org

Please include:

- Description of the security issue
- Affected component or file
- Steps to reproduce
- Potential impact
- Recommended remediation (if available)

---

## Response Timeline

Security reports will be reviewed responsibly.

Expected response process:

- Acknowledge the report within 7 days
- Investigate and validate the issue
- Apply fixes or mitigations where appropriate
- Communicate resolution status when possible

---

## Scope

This policy applies to:

- Website source code
- Next.js application components
- Frontend assets
- Configuration files
- Dependencies
- Build and deployment workflows
- Public documentation pages

---

## Security Considerations

Please report issues related to:

- Exposed credentials or secrets
- Cross-site scripting (XSS)
- Dependency vulnerabilities
- Incorrect security configurations
- Unauthorized access possibilities
- Data exposure concerns

---

## Responsible Disclosure

I request that security researchers:

- Avoid public disclosure before remediation
- Provide sufficient technical details for investigation
- Allow reasonable time for fixes

Responsible reporting helps keep this website secure and reliable for visitors.
